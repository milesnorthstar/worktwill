# 连续性核心服务首版与定向结果

2026-11-21。正式Rust核心、设置UI与continuity原生候选已实现，目标WPS子集取得真实证据；完整U8/V1仍未通过。早期阶段记录保留，最新状态见末尾。

## 实现

- windows_snapshot在同一句柄读File ID、创建时间、Object ID、大小/修改时间，拒绝reparse、目录、硬链接和非NTFS；读取与创建分开。原platform::identity语义不变。
- schema9新增目录追踪policy、逐文件anchor及binding_history。旧库不默认启用，备份恢复强制禁用历史同意；不删除既有文件Object ID。
- document_continuity实现显式目录同意、重要文件锚点建立、统一续接事务。扫描、通知、导入及原路径打开失败恢复共用入口。卷+File ID范围查询发现竞争记录，创建时间仍用于完整身份复验；两个UUID冲突直接拒绝，不合并。
- 事务复验目录授权及物理快照、恢复代次和绑定版本，撤旧file grant、保存原历史依据、更新绑定/目录关系/搜索投影/修订及修改活动；失败整体回滚。旧活动identity不改写。
- recent通过终止于当前identity的绑定链解析，并另验旧活动历史权限；人工relink没有这种链。当前访问仍按现授权和打开前复验。
