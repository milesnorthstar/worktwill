## 必须先解决的方案问题

当前方案不能覆盖本机 WPS 的日常保存，继续收集其他通过项不会改变这一失败。要满足原目标，必须找到并实际验证可靠的文档延续方案；若选择排除该保存场景或允许写入身份元数据，则必须由产品负责人明确修改原有要求。当前没有这样的批准，也没有已验证的替代方案。

不能只因文件留在相同路径，就把“身份无法确认”的处理改成自动继承；也不能把手动重新指向登记为U8成功。可审阅选项见 [U8阻塞记录](WINDOWS_U8_BLOCKER.md)。这一决策不能自动豁免表内其他未验证项。
