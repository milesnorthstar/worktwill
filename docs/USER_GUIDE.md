# WorkTwill 使用说明

WorkTwill 用工作区组织本地文件引用和网页链接，原文件留在原处。安装步骤见 [双语离线说明](INSTALLATION.txt)和[安装更新](INSTALL_AND_UPDATES.md)，当前安装包以[官网下载页](https://worktwill.haoclub.com/zh/download)为准。

## 授权位置与文件

首次使用时，在个人工作台点「选择文件夹」，选一个平时放文件的目录。读取后从「最近资料」点开文件，或按文件名搜索。若先在快捷搜索或完整搜索输入了关键词，也可以直接从搜索中选文件夹并继续搜索。单独授权文件时，范围只包含所选文件。

暂停扫描会保留已有授权。撤销授权后，不可访问资料的名称等信息会从全局查询隐藏；工作区可以保留匿名关联，重新授权后再核对。撤权不会删除原件。位置暂时离线与撤权不同，不要通过删除应用数据库解决暂时不可用。

## 个人工作台与工作区

首页提供最近修改、最近打开、工作区入口和便签。左侧导航包含个人工作台、工作区、动态和收藏；没有独立「所有文件」页面。

为项目、客户或工作事项创建工作区，再添加文件或保存网页。同一资源可加入多个工作区，不复制原件。跨区移动只调整引用；从一个工作区移除引用不会删除原件、其他工作区中的引用或收藏。

拖入文件后，已有授权的文件会直接尝试加入。还有文件需要授权时，可点「授权并加入」并确认，也可以点「跳过未授权文件」保留已加入的资料。只需查看结果时，点「关闭」。

在工作区资料行的操作区点击「从本工作区移除」即可移除单项，无需先勾选；勾选多项后使用底部浮动工具栏批量操作。收藏页点击星标取消收藏。网页的「删除网页」会在确认后删除它在整个应用中的记录，与从当前工作区移除不同。

在最近资料、收藏、工作区详情和完整搜索结果中，右键文件或网页链接可打开、收藏或加入工作区。工作区内可选择「从此工作区移除」。只有确认「删除已保存的链接」才会移除应用内该链接的所有记录。右键侧栏中的工作区可改名或删除。右键操作只作用于点中的那一项。搜索框和便签的右键菜单仍可复制、剪切和粘贴。

勾选资料后，可以在列表表头操作已选资料。勾选和取消时，资料行保持原位。

普通更新在后台读取完成后替换列表，不会先清空工作区和计数。通过「添加文件」搜索加入时保留搜索词和结果，已关联的文件显示「已加入」。撤销授权或恢复数据等使旧授权失效时，仍会立即隐藏旧资料。

通过资料的打开操作调用系统默认程序；打开网页使用系统浏览器。原件不可用或身份待确认时，按界面提示重新选择并确认原件，不要用同名文件自动代替。

## 搜索

应用内按 macOS **⌘K** / Windows **Ctrl+K** 打开快捷搜索，输入名称或位置线索。可使用方向键、Enter 和 Esc；同名资料需要核对位置。

完整搜索页支持类型、工作区、修改日期和路径/网址筛选，结果按需加载。查询覆盖文件名称/路径、网页标题/URL和工作区名称，不读取文档正文。查询条件或授权变化可能使旧分页失效，需要重新读取结果。

修改日期可直接输入 `YYYY-MM-DD`，也可点日历图标选取。开始和结束日期都包含当天，变更一端后，另一端的日历会禁用超出范围的日期。下拉菜单可用方向键浏览、Enter 确认、Esc 收起。

## 网页与联网行为

保存网页时可启用或关闭自动获取标题。启用会访问目标站点并使用 Cloudflare DNS；关闭后可手动填写标题。保存的是 URL 引用，不是离线网页副本，也不包含浏览器登录会话。

本地文件检索与整理不依赖网络、账号或 AI。支持更新的版本另有联网检查和下载，见下文。

## 动态、收藏与便签

动态按日历显示应用观察到的首次发现、修改及应用内打开。文件修改时间和观察时间含义不同；应用未运行时的每次编辑无法完整还原，也不提供文档版本历史。

日期下方的圆点表示当天有记录。选中日期查看当天，点「整月」恢复月份视图，点「今天」回到当天。

收藏便于跨工作区访问常用资料。便签为应用内纯文本数据；看到「已保存」才表示最新内容已得到确认。保存失败时保留草稿并重试，冲突时按提示处理。强制结束应用不保证未提交的内存草稿可恢复。

## Windows 文档追踪

在符合条件的内置 NTFS 管理目录中，可明确开启文档追踪。它与读取目录的授权分开：开启后，WorkTwill 可为收藏或加入工作区的文件按需建立系统 Object ID，以辅助验证保存后的连续性。停止追踪或撤权不删除已有标记。

此能力不保证所有编辑器、所有替换保存或身份冲突都能自动恢复。复制、另存为和同名重建不能仅凭路径继承原引用；无法确认时需要人工处理。

## 备份、恢复与更新

设置中的备份保存工作区、关系、URL、收藏和便签等应用数据，不包含原文件。备份可能含敏感名称和路径，需要妥善保管。恢复后需要重新授权文件访问；不要把备份当成原文件备份。

启动后和定期检查更新；设置可手动检查或关闭自动下载。关闭下载仍会检查版本。已验证下载就绪后，由用户确认重启安装；安装前尝试保存便签，失败时不继续安装。没有更新器的旧版需要先手动安装支持更新的版本。

## 支持边界与问题反馈

当前以普通内置磁盘本地目录为范围，不提供网络盘、外置盘和云同步目录的专门适配。macOS 和 Windows 分别验证，真实编辑器保存、身份恢复、安装和升级的表现可能不同；不保证所有安全替换保存都保持引用。

预览版没有系统代码签名或 macOS 公证，更新包验签与系统签名不同。遵循安装说明与设备管理策略；签名、损坏或安装失败时不要关闭系统保护来继续。

读取失败时可使用界面「重新加载」；持续失败则保留应用数据及备份，通过 [GitHub Issues](https://github.com/milesnorthstar/worktwill/issues)报告系统、应用/编辑器版本、复现步骤和预期/实际结果。截图与日志先去除个人文件名、路径和内容，不要公开数据库或备份。
