# WorkTwill 使用说明

这是本地个人工作台，无需注册或登录。资料保存在这台电脑中，不会自动迁移其他软件的账户和数据。

本说明的导航对应当前源码：左侧是主导航，右侧是内容，默认首页为「个人工作台」；2026-11-21已决定删除「所有文件」独立页面。[macOS arm64历史候选038](../deliverables/WorkTwill-v0.1.0-v1-candidate-038-macOS-arm64.zip)尚不包含本次删除，旧包的旧数据读取、资料拖动手势及原生确认窗口归属修复已取得对应原生证据。033另补已知文件变化的快速刷新，三次本机WPS保存观察在约0.7–1.9秒内更新动态；034另补已授权目录中新文件的通知收录，一个真实WPS另存副本约2.6秒可查；这些不代表所有软件和负载的响应保证。完整支持范围仍在验收，具体边界见[验收记录](ACCEPTANCE.md)。

如果首次读取失败，页面会显示「读取失败」和「重新加载」。可点击重试；若仍失败，保留现有数据与备份，不要删除应用数据目录。029包含旧数据格式升级，升级后使用对应新包；旧候选包与新版数据库不能混用。

## 第一次使用

1. 打开应用，默认进入「个人工作台」，在空态点击「添加管理位置」，选择一个现有文件夹。也可点「桌面」「下载」「文档」，让选择器从常用位置开始；确认前不会授权或扫描。只扫描你明确选择的位置，文件保持原样。
2. 扫描期间即可搜索已经发现的资料。右侧内容顶部的全局搜索框也可用 `⌘K` / `Ctrl+K` 聚焦。
3. 在「工作区」新建一件正在处理的工作，例如「客户 A 合同」。从全局搜索添加文件，或点「选择本地文件」。
4. 也可先多选资料，再点「新建工作区并加入」并命名；失败时保留输入，成功后进入新工作区。普通「新建工作区」仍创建空工作区。
5. 同一份资料可以加入多个工作区。单击名称选择，单击或点击打开按钮，用系统默认软件打开原件。

## 个人工作台与导航

左侧首项「个人工作台」是默认首页；工作区、动态和收藏都从左侧进入。全局搜索始终位于右侧内容顶部，无需先切换到搜索页面。

窗口变窄时，左侧主导航收为图标栏，工作区仍可从主入口进入；窗口高度不足时可纵向滚动侧栏到设置入口。首次还没有资料时，以「添加管理位置」开始，只有确认选择后才授权扫描。

个人工作台展示当前顺序中的前3个工作区卡片，以及现有资料列表和最近修改、最近使用等入口。卡片反映你的工作区顺序，不表示上次打开记录；可从卡片进入对应工作区，或前往全部工作区。没有资料或工作区时提供添加和创建入口，不生成演示内容。

「收藏」直接显示收藏资料，不再提供切换到其他资料模式的通用 Tab。浏览资料可使用首页现有筛选；查找资料使用顶部搜索及「查看全部搜索结果」，结果中仍可多选并加入工作区。要按日期回顾文件变化，再进入「动态」。

左侧工作区列表可滚动，显示全部工作区。读取管理范围时先显示读取状态，读取完成后再显示实际授权数量或添加入口。「最近使用」只属于实际打开过的当前文件；重新指向另一份文件不会把旧文件的使用时间算给它。

## 拖入文件

可从 Finder / Explorer 拖入文件；拖到工作区卡片或工作区按钮会直接关联该工作区。应用内也可以将一份或多份选中资料拖到工作区。

已在管理范围内的文件先加入。权限外文件会出现在结果中，点击「仅授权未加入的文件」并确认后补入；只授权这些文件，不扫描其父文件夹。取消不会撤回已加入项，重复加入不产生第二份引用。文件夹请通过「添加管理位置」管理。

## 添加网页

点「添加网页」，输入或粘贴网址。裸域名会补成 HTTPS，标题自动填写后可修改，也可直接以域名保存。自动标题会访问目标网站，并经 Cloudflare 解析域名；不使用浏览器登录状态。可以关闭自动获取，手动填写标题和网址。

无法抓取、超时或需要登录的网站仍可手填保存。网页在系统默认浏览器打开，不保存网页登录会话或离线正文。

## 动态与日历

从应用左侧主导航进入「动态」。日历与时间线位于右侧主内容内部：在动态内部左边选择日期、整月、活动类型和工作区，中间按天回顾文件修改、首次发现和应用内打开，右边可返回工作区或最近活动资料。离开动态后，其他页面继续使用各自的资料与工作区布局。

「首次发现」指本应用第一次收纳，不是文件创建日期。「文件修改时间」和「本应用发现时间」可能不同。应用关闭时的多次编辑不会被还原成完整编辑历史。

动态中的名称保留事件发生时的观察；重新指向以后，打开按钮访问当前引用，不提供旧版本恢复。撤销旧资料最后一份授权后，其历史名称也隐藏；旧位置仍在有效管理范围时可继续查看旧观察，当前引用没有权限则不能打开。较早格式迁移的事件可能只有当前名称，不能据此还原完整历史。

## 查找与整理

- 快速搜索按类别展示，但默认高亮遵循匹配相关性；同名候选等待明确选择，可用方向键后回车打开。
- 搜索可以限定当前工作区；「查看全部搜索结果」支持类型、排序、修改日期和路径/网址前缀。日期「至」包含所选当天。结果页的「返回」恢复来源工作区与分类，或原收藏模式。
- 修改搜索关键词、范围、筛选或排序会清除选择，避免把当前不可见的旧资料一并提交。
- 加载更多搜索结果时，如果资料或授权已经变化，会重新显示第一页，并清除原有选择；可在更新后的结果中继续查找。
- 收藏按钮把常用资料留在「收藏」。工作区顺序可在设置中调整。
- 「从本工作区移除」只解除当前关联；「移到工作区」只转移应用引用，原文件原地不动。批量失败项保留原有引用。
- 「删除工作区」保留原件、其他工作区和收藏。网页的「删除网页」会从所有工作区、收藏和动态中移除此网页记录，确认弹窗会说明范围。

## 管理范围与备份

设置中可暂停扫描、撤销位置或单文件授权、排除子目录。排除项旁的 × 可恢复该子目录的索引。撤销最后一份授权后，工作区保留匿名引用；重新选择位置后可恢复访问。

「备份数据」保存工作区、关联、收藏和网址，不包含原文件。恢复会替换当前应用资料，事前自动保留当前库副本；恢复后需要重新授权目录或单文件。备份含资料名称、路径和文件定位信息，请保存在你认可的位置。

## 当前交付边界

本机已验证 WPS 12.1.26046 在 APFS 的原位保存和另存为，并用核心进程重启核对 UUID、两个工作区和收藏。完整 WorkTwill 窗口 U8、Word、安全替换保存、Windows 和签名安装尚未验收。

如果系统已接受打开，但恰逢资料、路径或授权变化，应用会明确提示本次活动未记录；这不表示系统拒绝打开，也不表示新文件已被使用。

## V1.3.1 搜索与便签

从左侧“搜索与筛选”可以直接进入空白搜索页；输入词后查找，支持类型、修改日期、工作区、路径/网址前缀与排序，更多结果继续加载。顶部或⌘K打开大型快捷搜索；Esc关闭保留原完整搜索，只有“查看全部搜索结果”会提交快捷层的新词。

资料名称单击打开，复选框负责多选。文件/网页行尾的收藏、定位或编辑只执行自身操作；工作区名称进入该工作区。最近打开时间指WorkTwill被系统接受并复验记账的打开，不代表阅读或系统浏览历史。

首页右侧可收起静态空间伙伴，便签不依赖工作区。便签自动保存、多行编辑、置顶、删除，首页显示至多三条，“查看全部便签”展开集合。只有当前正文确认提交后才显示“已保存”。失败保留当前内存草稿并可重试，关闭窗口先尝试保存；应用未退出时可返回首页重试。已保存内容重启可取回，强制退出可能丢失未提交草稿。备份含便签和应用关系，不含业务原件。
