WorkTwill · 首次安装与更新

官网：https://worktwill.haoclub.com/
安装与支持：https://worktwill.haoclub.com/guide
版本与 SHA-256：https://worktwill.haoclub.com/download

macOS
1. 从官网下载与你的芯片匹配的 DMG，打开后将 WorkTwill 拖入“应用程序”。
2. 推出安装磁盘，再从“应用程序”打开 WorkTwill。
3. 当前预览版尚未经过 Apple 开发者认证与公证。首次打开若提示“Apple 无法验证 WorkTwill”，确认来自官网下载后，先点击“完成”。
4. 打开“系统设置 → 隐私与安全性”，向下找到“安全性”，在 WorkTwill 的拦截记录旁点击“仍要打开”。
5. 在随后出现的确认框中点击“打开”，按系统要求确认身份。
没有按钮：先从“应用程序”尝试打开一次，再返回设置。公司或学校管理的电脑可能需要管理员处理。仍没有按钮时，请反馈弹窗截图、应用版本与 macOS 版本。
提示“已损坏”：暂停安装，检查官网是否有更新版本；新版仍报错时请反馈。旧版 1.3.1 请换用 1.3.2 或更新版本，无需删除应用数据。
提示“将损坏你的电脑”或明确的恶意软件提示：停止打开并反馈截图，不按普通“无法验证”提示处理。
反馈：https://github.com/milesnorthstar/worktwill/issues/new?template=bug_report.yml
Apple 说明：https://support.apple.com/zh-cn/102445

Windows（仅适用于官网已提供的 Windows 安装包）
1. 下载匹配的 EXE 安装程序，退出正在运行的 WorkTwill，再运行安装程序。
2. 当前版本未做 Windows 代码签名。如出现“Windows 已保护你的电脑”，先核对官网来源与文件校验值；确认信任后，可选择“更多信息 → 仍要运行”（若系统提供此选项）。
3. 若没有“仍要运行”或公司策略禁止安装，请联系电脑管理员。不要关闭 Defender 或 SmartScreen。
4. 安装程序按当前用户安装；如提示需要 WebView2，请按安装程序引导完成运行时安装。

后续更新
支持应用内更新的版本会自动检查新版；可在“设置 → 应用更新”关闭后台自动下载，也可手动检查或下载。
下载完成后选择“重启更新”，应用先保存便签，再安装并重新打开。也可稍后更新。
没有内置更新器的旧版本，需要先手动安装一次。请退出旧版后安装，保留应用数据目录，不需要先删除资料或卸载数据。
更新包使用独立签名并自动校验；这与 Apple/Windows 的系统代码签名不同，也不代表经过系统厂商安全审核。
线上更新是否可用以官网当前发布状态为准；没有新版或网络不可用时，仍可使用本地资料功能。

WorkTwill 无需账号，没有预置业务资料；仅处理你明确授权的文件或目录。
应用数据备份不包含磁盘原文件，请另行备份原文件。

English

Official downloads and checksums: https://worktwill.haoclub.com/en/download
Installation and support: https://worktwill.haoclub.com/en/guide

Mac: Open the matching DMG, drag WorkTwill to Applications, eject the disk image, and launch from Applications. This preview has no Apple Developer ID signing or notarization. If macOS says Apple cannot verify WorkTwill, confirm it came from the official website and click Done. Open System Settings → Privacy & Security, scroll to Security, and select Open Anyway next to WorkTwill. Click Open in the confirmation dialog and confirm your identity if requested.
If Open Anyway is missing, attempt a launch from Applications first, then return to Security. Managed computers may need administrator assistance. If it is still missing, report the dialog screenshot, app version and macOS version.
If the app is reported as damaged, stop installation and check for a newer official version. Replace 1.3.1 with 1.3.2 or newer without deleting application data. Report the issue if the latest build is still affected. Stop if macOS says the app will damage your computer or identifies malware; do not follow the unidentified-developer steps.
Report: https://github.com/milesnorthstar/worktwill/issues/new?template=bug_report.yml
Apple guidance: https://support.apple.com/en-us/102445

Windows (when an installer is published): Exit WorkTwill and run the matching EXE. This build has no Windows code signing. If SmartScreen appears, verify the official source and checksum before choosing More info → Run anyway, if offered. If blocked by policy, contact your administrator; keep Defender and SmartScreen enabled. Installation is per user. Follow the installer if WebView2 is required.

Updates: Open Settings → App updates to check or download manually, or control background downloads. Once ready, Restart to update saves your notes, installs, and reopens the app. Older versions without an updater need one manual installation. Exit the old version and retain the application data directory. Update signatures are verified independently of OS code signing and do not imply approval by Apple or Microsoft. Live update availability follows the published website status. Local file features remain usable without an update connection.

No account or preset business data is required. Only explicitly authorized files or folders are processed. App data backups do not include original files; back those up separately.
