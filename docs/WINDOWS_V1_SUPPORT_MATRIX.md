2026-11-21。整体结论：工程候选，完整Windows V1未验收。仅承诺逐行实际取得的证据；未验证不等于不支持。PRD §9.0后置的正式发行工作另记。

目录范围：以上仅普通本地目录（包括测试根下合成子目录）。网络盘、外置盘、OneDrive/iCloud等云同步目录专门适配明确不属本轮V1，不承诺已支持；位置不可用及身份不明仍须保留基本安全保护。不同普通目录名称/层级不能凭同一盘符直接推定全部原生矩阵完成。
