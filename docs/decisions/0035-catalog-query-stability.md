# 0035：扫描进度与查询事实分离、同根有效路径保持

日期：2026-11-20。状态：实现、回归、release及原生103项连续分页通过；完整Mac核心和Finder外拖尚未完成。

## 实际问题

038使用独占临时目录的103份TXT补验原生分页。037在名称排序下显示000至099，但两次点击加载更多均报告资料已更新并回到首页，未到达100至102。截图与原始状态保留，不能登记分页通过。当前另有真实目录在后台扫描，不暂停用户目录、不以业务文件充当夹具。

只读聚合观察发现全局revision持续增长。第二次采样没有增加或删除资源，2422条既有资源的名称和位置变化，其他采样字段未变；从发生位置变化的记录抽取20组，两条路径均仍存在、指向同一物理文件且链接数大于1。只记录聚合数量及摘要，不导出业务名称/路径。此采样解释可见的路径轮换来源，不证明所有后台变化均无效。

原实现还会在每次扫描批次、空批次及完成时无条件递增revision，即使只更新扫描代次/进度。确定性回归独立复现无内容变化重扫使100+3分页游标失效，以及同根硬链接候选抢占仍有效原路径。

## 决定

- Catalog继续拥有扫描提交事实。批次仅在资源、根映射、搜索投影或文件事件实际改变时递增revision；进度、代次及空批次不改变查询事实。完整扫描收尾仅在实际改变资源失联状态时递增版本；状态不变不反复写成修改。
- 同根候选与既有资源物理身份相同、两条路径均可访问时，只有既有路径仍在当前根、未排除、符合自动扫描边界且canonical path/当前物理身份一致，才保留其名称与位置。原路径消失、身份不同或被排除时，采用本次已复验候选。
- 候选路径与保留路径上的其他身份仍标为待确认；真实元数据变化、失联、范围映射新增或投影修复继续递增版本。不会为另一物理身份继承旧UUID。
- 不改搜索/时间线游标协议、session、permission_version、revision校验、恢复epoch、根代次和授权边界。真实写入后仍返回stale_cursor，客户端仍清旧页重读，不能混合快照。
- 不建立新缓存、别名表、额外扫描通道或重试循环，不承诺全部硬链接/跨根多路径行为，不扩展特殊目录支持。
- 全量和指定目录任务比较Core提供的前后查询revision：有变化仍发`catalog-changed`并同步清旧页；无变化只发`scan-progress`。前端复用overview读取进度，核对session/权限/revision及读取代次后才更新概览，不清已加载页或选择；若此时发现真实版本变化则重读。版本读取失败明确报告并保守清旧资料。通知不会传递第二套业务事实。

## 验证与代价

新增回归覆盖无变化重扫后100+3续页、真实修改/失联仍拒绝旧游标、同根路径稳定/原路径消失后同UUID取回，以及排除原路径与同路径替换状态。原有重叠授权、父目录替换、撤权/暂停、恢复ABA及扫描竞态检查保留。

首次038原生构建已实际到达100/101/102且末页无加载更多。随后遍历期间页面又回到100项，未捕获对应扫描完成前后的版本，不能确定这次是否存在其他真实变更。源码确认原生层对每次完成都无条件发catalog-changed，因此补上述进度通知分离，并加两项组件回归：无变化进度保留后页与选择；迟到进度不能覆盖撤权后的新概览或恢复旧名称。最终原生结果另记，不将首次失败遍历写成103项全部通过。

同轮原生观察到100→103项时首次切入虚拟列表，使外层长列表收缩、内部滚动从0开始。虚拟化起点改为完整首页的100项，使续页前后使用同一滚动容器；少于100项的短列表保持原行为。新增回归先失败，修后验证键盘可达的滚动区、原末项及新增后三项保留，完整UI最终141项通过。此修复不更改分页大小、资源事实或源文件。

每批读取当前根路径与排除项；只有路径不同的同身份候选才额外核对保留路径。SQLite仍写扫描进度/代次，业务版本不再用于表达进度。全量检查、构建和103项原生复验按实际结果追加，不以Core通过代替原生界面或Finder外拖通过。修前失败见`docs/validation/2026-11-20-catalog-stability-first-038.log`及`2026-11-20-native-pagination-038-*.jpg/json`。
