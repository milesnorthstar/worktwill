# 0002：V1 拖入、网页标题与文件日历时间线

日期：2026-11-19。状态：已实施；对应原生验收单列。依据为用户本轮明确批准，取代 PRD v0.5 中不主动获取标题、应用操作为主动态的对应旧约束。

- **Rust 持有文件授权和 UUID。** 原生窗口事件接收系统路径，短时 token 仅指向本次候选。松手立即发送started并固定工作区目标，后台捕获物理身份后才消费对应token，避免慢盘期间切换页面误加入其他工作区；后台读取避免窗口线程读慢盘；提交前重新检查对象、目标、授权。300 秒过期，禁止并发消费，首次目标绑定，仅未授权项可重试，完成可丢弃凭据。新拖入不被旧任务回包覆盖。OS 事件只有路径，首次捕获前不承诺句柄级身份原子性。
- **单文件授权只访问所选对象。** 已授权目录/文件先导入，未授权项经原生确认后补入；不扫描未授权父目录。重新指向复用原生选择时的对象快照；不同身份不继承旧单文件授权，明确选择可仅授新文件；合并保留有效授权并集。应用内 Pointer Events 仅携带 UUID，7px 起拖，Esc/失焦/取消后不关联。批量 Link/Transfer 在 UI 逐项调用正式 mutation 并汇总失败；单个资源的转移仍为 Rust 事务。核心多项调用保留整体原子语义，不误称其自身已改成部分提交。
- **URL 元数据是可关闭的附加网络操作。** 裸域名补 HTTPS，以 hostname 即时填标题，可编辑，晚回包不覆盖手填。关闭自动标题后可离线手填保存。原生请求限 5 秒、3 跳、256KiB HTML、200 字标题；固定 Cloudflare DoH，逐跳校验全部目标 IP 并固定连接，不用系统代理、不带浏览器登录态、不执行 JS。弹窗披露目标网站及 Cloudflare 请求；失败不阻止手填。当前仅 UTF-8/ASCII，登录页/JS 生成标题不保证可取。
- **动态是文件工作线索。** 默认文件修改、首次发现、应用内打开；管理操作次级筛选。修改事件保留文件 mtime 和观察时间，首次发现不是创建时间。不变重扫不新增修改事件；应用关闭期间不虚构逐次编辑。按本地日历边界查询，夏令时使用下一日本地午夜，事件/日历同权限同筛选，翻页版本变化从首页重读。
- **schema 递进到 v3。** v1→v2 增事件来源/mtime及 file_grants，v2→v3 增工作区 sort_order。恢复先暂存校验迁移，保留当前库安全备份，撤销目录与单文件授权，清回执，版本在当前库基础递增。遇未来 schema 拒绝写入。
- **视觉方向。** 白底、冷灰背景、克制蓝色，顶部导航；左日历与筛选、中间按日时间线、右快速返回。资料列表超过 100 项时固定行高窗口渲染，不持续堆叠所有 DOM 节点。研究不把联系人、任务、独立笔记带入本轮。

代价：安全限制可能让部分网站只能手填；独立文件改名后若未在授权目录重新发现，需要手动重新指向；观察型事件不等于审计日志；offset 分页以版本核对重读保证不混页，尚非版本化游标。标题请求仍有第三方 DNS 依赖，文件/工作区核心无联网前置条件。

后续：完整搜索的分页部分已由[决定0005](0005-versioned-search-pagination.md)推进为后端版本化游标；时间线和普通资料列表仍按各自版本核对协议处理。
