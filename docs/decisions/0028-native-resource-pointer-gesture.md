## 状态与路径

`ResourceList`在资料行pointerdown时将单项或选中UUID集合交给`useResourceDrag`；hook在window监听move/up/cancel、保留7px阈值，松手用`data-workspace-id`固定目标，经原有mutation写入关系。路径和授权仍由Rust掌握。搜索结果复用同一拖动入口，复选框及行操作按钮由既有guard排除。

## 最小修复

在guard通过后的资料拖动起点调用`preventDefault`，阻止WebKit的默认文字选取/拖动竞争Pointer手势。保持UUID、目标命中、阈值、取消、松手抑制点击和关系写入路径不变；不新增拖放服务或前端业务数据。

新增行为回归验证普通单击仍触发选择、拖动松手只关联一次且不误触选择；原取消/失焦与阈值回归保留。它保护输入默认行为变更后的组件交互，不模拟WebKit原生文字手势。统一检查207 Rust/137 UI通过。

修前原生失败及修后组件通过分开登记。继续打开窗口时Computer-Use连续返回`Sky Computer Use native pipe startup failed`，重置node_repl并按技能重新初始化后仍失败；没有改系统设置、结束客户端或换GUI桥接。**修后原生成功尚无证据，原因判断和修复效果须经真实拖动复验。** 外部Finder拖入、Retina/Windows缩放、多选与取消等完整矩阵保持待验收。
