# 0011：所选资料创建工作区与搜索上下文

日期：2026-11-20。状态：迭代013已实施；完整原生U2/保存重启等继续待验。

对照PRD U2发现“先多选，再新建并加入”缺少完整操作；普通新建会在成功刷新后清选择。列表选择栏现提供明确的“新建工作区并加入”，打开弹窗时保存所选UUID快照，显示数量；普通新建仍创建空工作区。失败保留名称与选择，取消不提交；成功进入返回的新工作区UUID。

扩展既有CreateWorkspace，增加可选resource_ids；None省略序列化，旧{name}请求及成功操作回执payload保持原格式。Rust提取原Link的逐项授权、1000项上限、去重插入和linked事件为私有link_resources；Create与Link复用。创建、搜索投影、关联、事件、revision和操作回执仍在同一个Immediate事务，任一资源失效全部回滚，不留下空工作区或部分加入。Unlink不要求visible，继续允许删除撤权占位引用；Transfer和UI既有Link/Transfer逐项部分成功策略保持原边界。此复合命令改变跨层DTO，但不修改schema或引入第二个Store。

快速搜索仍按工作区/文件/网页展示，默认高亮从后端全局首选UUID映射到分组后的索引；不再把第一展示组误当最佳结果。后端前两名规范化同名时不默认猜测原件，等待方向键、鼠标或分类跳转明确选择。高亮、组合框aria-activedescendant和Enter使用同一索引，方向键沿实际展示顺序移动。

完整搜索来源由React保存view/工作区UUID/mode/kind，提供明确返回入口；返回恢复原分类或收藏模式，若最新overview确认来源工作区已删除则返回工作区集合。来源不是持久业务数据，不新增后端接口或localStorage。修改query、kind、scope、日期/路径及排序都会重置当前加载集合并清选择；普通列表后续页版本变化重读首页也清选择。正常追加分页可保留选择。

撤权资源系统占位按permission_denied状态在ResourceList本地化；不按中文字符串识别或改写用户文件名。批量报告中的撤权占位使用既有可空名称，显示时用当前语言的不可用资料文案，避免保存固定中文。

Rust真实临时目录工作流核对五个不同目录同名文件的UUID集合、重复ID去重、操作重放、重开Store、既有引用/收藏及原件字节/大小/mtime不变；撤权、非法ID及超量失败不留工作区/FTS/事件/回执，重新授权后可明确重试。UI回归覆盖创建/取消/失败重试、默认相关性和同名等待、返回工作区/收藏/已删除来源、各条件变化及后页排序后的隐藏选择、快照重读、双语占位。Chrome合成夹具只验证呈现与浏览器交互，不作为真实IPC、授权、系统打开或应用重启证明。
