# 原生开发基线

状态：已实施首个开发增量，完整 V1 仍按验收推进。日期：2026-11-19。

采用现有批准的 Tauri 2、React/TypeScript、Rust、SQLite。原型保持原位，新前端置于 `desktop/`，平台壳在 `src-tauri/`，不依赖 UI 的领域与数据库放在同一 workspace 的 `worktwill-core` crate。服务职责保持在核心内部，不将每个逻辑服务拆成进程。

Rust DTO 使用 ts-rs 生成 TS 声明，生成漂移检查进入统一验证。SQLite 使用 rusqlite bundled 构建，版本由 Cargo.lock 锁定，不依赖用户 Python 或系统 SQLite。业务数据与 FTS 投影在同一事务维护，WAL 下独立连接查询。

搜索采用已实验的 trigram 与应用预生成短词 gram 索引，后置字面量核对；先授权/类型/工作区过滤，再选结果。当前规范化为 NFC + Unicode lowercase，不承诺完整 casefold/重音忽略；后续以真实查询集验证相关性。完整搜索取消、分页稳定性和端到端性能仍待补验收。

本机实验显示 Bookmark 对安全替换和删除后同名新建均可解析，Document ID 尚不可用。当前实现按物理身份连续维护 UUID，身份变化保留旧关系并允许用户重新指向；不能以路径相同自动换绑。该策略使基础闭环可运行，但不代表日常办公安全保存已达最终产品门槛。

首个安装包为本地开发构建，既没有发布签名，也没有商业许可/支付功能。恢复操作先备份当前库，恢复关系后撤销备份中的授权并要求重新选择管理位置；这是当前界面明确披露的保守恢复策略。
