A LITTLE HELP TO GET STARTED.

从这里，开始使用。

一个本地个人工作台。无需注册，也不需要安装 Node.js、Rust 或配置 AI。

对应版本：

当前是预览版，未做 Apple Developer ID 签名、公证或 Windows 代码签名，首次安装可能出现系统确认提示。请按官网下载页选择已提供的版本；各平台支持范围以下载页为准。

macOS 安装与第一次打开

首次打开可能提示“Apple 无法验证 WorkTwill”。当前预览版尚未经过 Apple 开发者认证与公证；这类提示表示 Apple 无法完成验证。请确认应用来自本官网下载页，再按以下步骤操作。

  1. 移入“应用程序”

    打开下载的 DMG，将 WorkTwill 拖入“应用程序”，然后推出安装磁盘。

  2. 尝试打开，点击“完成”

    从“应用程序”打开 WorkTwill。如果出现“Apple 无法验证……”提示，点击“完成”。

  3. 进入“隐私与安全性”

    打开“系统设置 → 隐私与安全性”，向下找到“安全性”区域。

  4. 找到 WorkTwill，点击“仍要打开”

    确认拦截记录对应 WorkTwill，再点击旁边的“仍要打开”。

  5. 确认“打开”

    在随后出现的确认框中点击“打开”，按系统要求确认身份。允许后，通常可以直接打开应用。

以上为操作位置示意，系统文案和布局可能因 macOS 版本有所不同。macOS Sequoia 起，请使用系统设置中的允许入口，不依赖“右键 → 打开”。

没有“仍要打开”按钮？

请先从“应用程序”尝试打开一次 WorkTwill，再回到“隐私与安全性”，向下查找“安全性”区域。公司或学校管理的电脑可能需要管理员处理。

如果仍没有按钮，请记录弹窗原文或截图、WorkTwill 版本与 macOS 版本，通过下方反馈入口联系我们。

提示“已损坏”或“将损坏你的电脑”？

这两类提示不按上面的“仍要打开”步骤处理。

  • 提示“已损坏”：请暂停安装，检查官网下载页是否有更新版本；新版仍报错时，请联系我们排查下载或签名问题。
  • 提示“将损坏你的电脑”或明确的恶意软件提示：请停止打开，并反馈提示截图。

旧版 1.3.1 提示“已损坏”？请下载 1.3.2 或更新版本并替换旧应用，无需删除应用数据。若新版仍有相同提示，请联系我们。

Windows 安装提示

以下步骤适用于官网下载页已提供的 Windows 安装包；当前可用版本与平台状态以下载页为准。

  1. 下载匹配的 EXE，退出正在运行的 WorkTwill，再运行安装程序。默认按当前用户安装；如提示需要 WebView2，请按安装程序引导完成。
  2. 如果 SmartScreen 显示“Windows 已保护你的电脑”，先核对官网下载来源与校验值；确认信任后，可选择“更多信息 → 仍要运行”（若系统提供此选项）。
  3. 如果没有“仍要运行”或公司策略禁止安装，请联系电脑管理员。保留 Defender 和 SmartScreen 的系统保护设置。

后续更新与手动安装

在“设置 → 应用更新”中检查新版或控制后台自动下载。下载完成后可选择“重启更新”或稍后处理；重启前会先保存便签，安装后重新打开。

尚未内置更新器的旧版需要先手动安装一次。请退出旧版后安装，保留应用数据目录，无需先删除资料。macOS Apple 芯片版已验证从 1.3.1 在线升级到 1.3.2，其他平台与升级路径需单独验证。

当前版本未做 Apple Developer ID 签名、公证或 Windows 代码签名；更新包仍会自动校验独立签名。这不代表经过 Apple 或 Microsoft 安全审核。

下载离线安装说明（中英双语）

打开后进入「个人工作台」，无需账号，没有预置业务数据，也不会自动扫描你的电脑。

先添加一个管理位置

点击「添加管理位置」，选择一个现有文件夹。桌面、下载和文档只作为选择器起点，确认前不会授权扫描。也可以仅授权选中的几份文件，不扫描其父文件夹。

应用只索引明确授权的资料。原文件保持原样，索引与工作区关系保存在应用独立的本地数据区。

把一件事的资料放在一起

  1. 新建一个工作区，例如「客户合同」或「新同事入职」。
  2. 从搜索结果添加文件，也可使用「选择本地文件」或拖入文件。
  3. 点击「添加网页」粘贴网址，自动获取的标题可以编辑，也可以关闭自动获取并手填。
  4. 点击资料名称，用系统默认软件打开原件。

同一份资料可以加入多个工作区。从工作区移除资料、转移关联或删除工作区，只改变引用，不会移动或删除磁盘原件。

随时查找，回顾动态

右侧顶部搜索常驻，macOS 可用 ⌘K 聚焦。搜索覆盖已索引的名称、路径、网址和工作区等信息，当前不搜索文件正文。可进一步限定工作区、类型与日期。

「动态」可以按日查看文件修改、首次发现和应用内打开。「首次发现」是应用收纳时间，不是文件创建时间；应用关闭时的多次编辑不会还原成完整编辑历史。

文件改名、移动与重新指向

当前 macOS 候选版接入了部分同物理对象改名与同卷移动定位，旧管理位置可能需要明确重选。跨卷移动和某些软件的替换保存仍需另外验证。身份无法确认时会保留关联，允许你通过「重新指向」明确选择原件，不会凭同名自动接管。

本地数据与备份

macOS 应用数据位于 ~/Library/Application Support/app.worktwill.desktop/。设置中的「备份数据」保存工作区、关联、收藏和网址，不包含原文件。备份含资料名称、路径和定位信息，请保存在认可的位置。

恢复会替换当前应用资料，并事前保留当前库副本。恢复后需重新授权目录或单文件。请同时妥善备份原文件；应用备份不替代原文件备份。

已知支持边界

可用的 macOS Apple 芯片和 Windows x64 预览包以下载页为准。不同编辑器的保存、跨卷身份连续性和升级路径需要分别验证；不能从安装或构建成功推断全部支持。
